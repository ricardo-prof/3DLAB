# 3D Lab — Laboratório de Fabrico Digital

Plataforma educativa de apoio ao Desenho Assistido por Computador, modelação 3D e impressão 3D.

## Publicação no GitHub Pages

1. Cria um repositório público com o nome `3d-lab-laboratorio-fabrico-digital`.
2. Descarrega e descompacta este pacote.
3. No repositório, escolhe **Add file → Upload files**.
4. Carrega o conteúdo desta pasta (incluindo `index.html`, `style.css`, `script.js` e as pastas).
5. Seleciona **Commit changes**.
6. Abre **Settings → Pages**.
7. Em **Build and deployment**, escolhe **Deploy from a branch**.
8. Seleciona `main` e `/ (root)` e guarda.
9. Aguarda a publicação. O endereço esperado é:
   `https://ricardo.uxdesign.github.io/3d-lab-laboratorio-fabrico-digital/`

## Estrutura

- `index.html` — página inicial.
- `style.css` — identidade visual e adaptação a dispositivos móveis.
- `script.js` — interações da navegação.
- `pages/` — páginas internas a desenvolver.
- `assets/` — imagens e elementos gráficos.
- `recursos/` — materiais pedagógicos e modelos 3D.
- `projetos/` — desafios e projetos.

## Notas

- O site é estático: não utiliza PHP nem base de dados.
- Os conteúdos e ficheiros publicados num repositório público devem estar preparados para acesso público.
- Não publicar dados pessoais de alunos, fotografias identificáveis ou trabalhos associados a alunos sem autorização e validação institucional.
- As fontes tipográficas são carregadas do Google Fonts; se não houver ligação à Internet, serão utilizadas fontes de recurso.
